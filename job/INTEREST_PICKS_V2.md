### 2-4. 순위와 등급
- 점수순으로 정렬하고, 동점이면 60일 고가에 가까운 순이다. 상위 10개를 내고, **5점 미만은 노출하지 않는다.** 4점 이하는 초과수익이 음수였다.

| 점수 | 등급 | 상승여력 표시 |

| 8점 이상 | 적극매수 | 높음 |
| 6~7점 | 매수 | 보통 |

### 진입 시점 재검증: 당일 종가 매수 (2026-11-17)
모의 fire는 15:21 동시호가(=당일 종가)로 사므로, **현행 설정**(등락 4~12% + 폭발 제외 + 5점↑ 상위 10)을
같은 2년 패널에서 진입 시점만 바꿔 다시 계산했다. 10일 보유, 순수익은 비용 0.25% 차감, 초과는 같은 진입 방식의 전 종목 평균 대비.

| 기간 | 다음날 시가 초과 / 순수익 | **당일 종가** 초과 / 순수익 |
|---|---|---|
| 24.9~25.8 | +0.88%p / +0.65% | **+1.04%p / +0.95%** |
| 25.9~26.8 | +0.75%p / +0.38% | **+0.81%p / +0.75%** |
| 26.9~ (368건, 10일 뒤 데이터가 있는 것만) | +0.22%p / -3.35% | **+0.06%p / -3.74%** |
| 전체 4,937건 | +0.77%p / +0.23% | **+0.86%p / +0.50%** (상승 1.21배 · 하락 1.00배) |

- 추천 종목의 다음날 시가 갭은 평균 +0.28%(전 종목 +0.23%)로 밤사이 우위가 없다 → 종가에 사도 손해가 없고 전체로는 약간 낫다.
- 최근 구간(26.9~)은 두 방식 모두 우위가 거의 없다(하락장, 표본 368건).
- 한계: 패널은 최종 종가로 신호를 계산했다. 실제 15:20 신호는 마감 직전 값이라 약간 다를 수 있다.
- 화면 설명 문구는 이 '당일 종가 진입' 수치(+0.9%p, 기간별 +0.1~+1.0%p)를 쓴다.

### 등락률 상한 8 → 10 → 12% 근거
- 슬롯 시뮬레이션 조건: 10종목, 10일 보유, 종가 매수, 비용 0.25%.

| 상한 | 손절 없음 (월평균) | 손절 -20% (월평균) |
|---|---|---|
| 8% | +2.7% | +2.0% |
| 10% | +3.4% | +2.4% |
| 12% | +3.5% | +2.8% |

- 등락 구간만 따로 보면(시장 대비, 세 기간):
  - 8~10%: +1.26 / +1.43 / +0.13%p

## 6. 모의 계좌 연동 (fire, 15:21)

| 항목 | 이전 | 지금 |
|---|---|---|
| 매수 대상 | fire SQL 통과 ∩ 직접 체크 | **오늘 v2 추천 상위 10개 전체(적극매수·매수·관심) ∪ 직접 체크** |
| 매수 순서 | 종가위치 순 | v2 점수 순 |
| 추천 파일이 30분 넘게 묵었을 때 | — | 추천은 빼고 직접 체크만 매수 (추천 생성이 멈춘 이상 상황 대비) |
| 체크 유효기간 | 계속 유지 | **평일 20:00 일괄 해제.** 해제 잡이 못 돌았어도 직전 평일 20:00 이전 체크는 무효 |
| 종목당 금액 상한 | 가용현금 × 90% ÷ 20 | **÷ 10 (약 9%)** |
| 시장폭·종가위치 필터 | 꺼진 채 코드에 남아 있었음 | 코드에서 제거 |
| 최대 보유 | 5영업일 | **10영업일** |
| 손절 | -6% | **-20%** |

- 직접 체크가 의미 있는 건 **상위 10개 밖의 종목을 추가로 사고 싶을 때뿐이다.**
- 매수하는 10개는 15:20쯤 생성된 파일 기준이다. 낮에 화면에서 본 목록과 다를 수 있다.
- 실계좌 fire 매수는 계속 꺼져 있다. 실계좌 청산은 -6% / 15영업일 그대로다.
- 하루에 -25% 넘게 갭 하락하면 손절하지 않는다. "데이터 이상"으로 보고 매매를 멈추는 기존 안전장치(`ANOMALY_RATE`)가 그대로다.

| 보유 10일, 손절 -20% | +2.0% |
| (적극매수만) 손절 -15% | +2.4% |

- **-6%는 너무 좁았다.** 출렁임이 큰 중소형주가 손절된 뒤 다시 오르는 경우가 많아, 이기는 비율이 50%에서 33%로 떨어졌다.
- **-20%는 사고 보험 성격이다.** 평소에는 거의 걸리지 않고 거래정지나 악재성 폭락만 막는다.
- **계좌 최대 낙폭은 손절 폭과 무관하게 -50% 안팎이었다.** 큰 손실은 시장 전체 급락에서 온다.

## 7. 검토했지만 채택하지 않은 것

| 아이디어 | 결과 |
|---|---|
| 승률 80% 이상 | 어떤 조합으로도 최대 52~57% 수준이라 불가능 |
| "크게 먹기"(타이트 손절 + 트레일링) | 수익/손실 배율은 4.4~4.8배가 됐지만 승률이 16~20%로 떨어져 본전 수준이었다 |
| 손절 없음 + 5일째 마이너스면 청산 + 15% 이상 수익 후 -12% 트레일링 + 최대 60일 | 적극매수 기준 월 +1.6%, 최대 낙폭 -41%. 아직 결정하지 않은 제안이다 |
| 기관 5일 순매수 표시 | 사용자 기각 |
| 첫 급등·외국인 급증을 점수에 반영 | 표본이 작아 참고 목록으로만 둔다 |
| 시장 급락기 매수 쉬기 | 시뮬레이션상 보유 10일 기준 +2.9~3.5%로 좋아질 여지가 있었으나 구현하지 않았다 |

## 8. 한계와 재검증 일정

- **장중 추천은 검증되지 않은 근사다.** 백테스트는 종가 신호 → 다음날 시가 매수 기준이다. 15:21 매수는 그날 종가 직전 데이터다.
- **"시장보다 나은 종목"을 고르는 장치다. 하락장을 피하는 장치가 아니다.** 2026-09 이후는 시장 자체가 크게 빠져서(10월 종목 중앙값 -15%) 절대수익이 음수였다.
- 피처 정의는 `universe_snapshot.py`와 백테스트가 글자 그대로 같아야 한다. 구간이나 피처를 바꾸면 둘 다 고치고 재검증해야 한다.

| 시점 | 할 일 |
|---|---|
| 모의 결과 몇 주 누적 후 | 상한 10% vs 12%, 상위 10 vs 적극매수만, 손절 -20% vs 없음 비교 |
| 2026-12 중순 | `candidates` 로그로 장중 추천 vs 종가 추천 성과 비교 |
| 2027년 초 | 수급 데이터가 쌓이면 외국인 급증·첫 급등 재검증, 점수 반영 여부 결정 |
